{# phaze-cvn6.3: user-resizable columns, dependency-free (no JS build step -- Alpine only). A `` is the single point of truth for every column's rendered width: EACH header's resize handle drags `$store.colResize` (registered in base.html/shell.html next to the theme store, same localStorage-persistence shape) and every `` here reads that same store, so a header and its column's cells always share one width with no per-cell duplication. Why a store and not component-local state: this whole `

The store is a page-level singleton untouched by the swap; the swapped-in `:style` bindings just re-read it, so a chosen width survives sorting, filtering, paging AND (via localStorage) a reload/bookmark. table-layout stays the browser default (auto), not `table-fixed`: the FILE cell already carries `truncate` (overflow:hidden + ellipsis + nowrap), and content that is clipped rather than measured is exactly what lets auto-layout honour an explicit `` width instead of growing the column to fit it -- so dragging FILE wider/narrower works precisely because it already truncates.
