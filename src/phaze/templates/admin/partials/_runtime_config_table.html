{# Runtime config admin table (phaze-mvq8z.6, ADR-0019 (runtime config hot-reload) §3/§10/§15). Lists every RELOADABLE key with its live effective value + source layer (override > file > env > default, phaze.runtime_config.Layer) and an inline set/clear control per row, followed by a read-only list of RESTART_ONLY_KEYS labeled "requires restart" (§5) -- these never get a form, because a live change to one is rejected by the core regardless of what an operator could submit here; showing them read-only (rather than omitting them) documents the reloadable/restart-only split rather than leaving an operator to guess which keys this page simply does not mention. No auth of its own (ADR-0019 (runtime config hot-reload) §10 -- matches the LAN posture of route_control / admin_agents / every other operator-facing admin surface in this repo); the compensating control is the structured audit line every reload (or rejection) emits server-side, not anything rendered here. Every row's form hx-posts to POST /admin/runtime-config/{key} and the Clear control hx-deletes the same path; BOTH swap the WHOLE table (#runtime-config-table, outerHTML) rather than just their own row -- a single write can in principle change what another row's SOURCE reads as (the override provider is read fresh on every reload), so one swap target keeps every row honest about what the store just resolved, rather than risking two independently-swapped rows disagreeing with each other. #}
