{# phaze-7u4sy (C3): the NON-MODAL docked file-record inspector, used by the Files stage at xl and up. A persistent sibling of
in shell.html's body row, so it lives OUTSIDE both swap hosts (#stage-workspace and #files-table-view) and survives every rail, sort, filter and pager swap. It is fed by the same GET /record/{file_id} fragment as the modal record_host.html, swapped into #record-dock-body. Below xl, and on every non-Files stage, record_host.html stays the sole owner and this aside is display:none (the hidden xl:flex classes) with an EMPTY body. Contract, mirrored by tests/browser/test_files_record_dock.py: * No role=dialog, no aria-modal, no x-trap, no inert: Tab walks the table and the dock normally. * Selecting another row REPLACES the record; focus stays on the row (the dock never steals it). The selected row carries aria-current=true. ArrowDown/ArrowUp move between visible rows, Enter opens the focused row through the row's existing guarded GET. * Escape closes the dock only while focus is INSIDE it (a nested open dialog or the palette keeps its own Escape). Close returns focus to the row that opened it. * ONE owner per open. recordHostFor() is the single decision; the capture-phase listeners below aim the opener's hx-target at the chosen host BEFORE htmx resolves its target (a later change at htmx:beforeRequest does not retarget the request), and BOTH hosts' record:open handlers consult the same function, so one event can never open the modal and the dock together. * Exactly one record tree exists at a time (stage-pill ids are unique): opening in the dock empties #record-body, closing/crossing empties the dock, and a response that no longer owns its host is rejected at htmx:beforeSwap instead of being repaired after it showed the wrong file. * Crossing the xl boundary in either direction closes whatever is open (releasing the modal's inert/trap through its own hide()), so no inert or trap survives a resize. The component is a global function (as in cmdk_modal.html) so its source never sits inside a double-quoted x-data attribute. #}
