# Local release metadata extraction

Date: 2026-10-09. Bead: phaze-7gngs. Epic: phaze-kf7jr.

`extract_release_metadata` in `src/phaze/tracklist_providers/local_release.py` accepts a supplied `SourceRead`, source format and optional `LoadBudget`. It returns immutable `ReleaseExtraction` containing `ReleaseFact` values, completeness and bounded evidence. This pure function performs no reads, scheduling, database writes or tag/selection changes. Downstream orchestration composes the facts into a `Snapshot` and persists it through `store_snapshot`; the retained read observation can be its explicit parent.

TXT/NFO support conservative `Label: value` and `Label = value` fields: artist/performer, title, album, event, date/year, venue/location, label/catalog, genre, source/ripper/encoder, quality/bitrate, duration/length and set type. CUE supports set-level PERFORMER, TITLE, CATALOG and recognized REM headers before the first TRACK directive. Fields after TRACK remain track scoped, including later FILE sections. Unsupported keys, prose and decoration are referenced in evidence and remain available in unchanged source text.

Every fact retains the original value, one-based source line and half-open absolute character span into `SourceRead.text`. Offsets count decoded Python characters, including BOM and CRLF. CUE quote wrappers remain in the original value; semantic values omit paired quotes. Unbalanced quotes and trailing tokens after a quoted CUE value remain unknown, with syntax evidence and no normalized value. Conflicting values remain separate facts marked conflicting. Equivalent supported units may agree without losing either original value.

Only valid ISO full dates normalize to an exact calendar date. Year/month partial dates retain their precision with inferred interpretation; ambiguous or invalid dates retain unknown interpretation. Explicit bps/bit/s, kbps/kbit/s and Mbps/Mbit/s normalize using decimal SI units to bit/s. Explicit duration HH:MM:SS or MM:SS and seconds suffixes normalize to seconds; invalid ranges, unitless numbers and quality prose do not imply numeric values. Numeric grammars have finite digit limits to avoid precision loss or oversized integer work.

The scan respects decoded-character, UTF-8 byte and line budgets, with at most 256 facts and 64 evidence entries. Lines over 4096 characters are skipped with incomplete evidence. Partial reads stay incomplete; an unterminated tail is excluded when the read or parser budget may have cut its value. Budget evidence never replaces original text. Completeness describes this release metadata scan, and explicit `release_metadata_only:no_track_enumeration` evidence prevents a trackless snapshot from claiming a parsed tracklist. Existing local adapter truncation behavior is unchanged; future import orchestration owns composition with track parsing.

Synthetic fixture tests cover exact spans/Unicode/CRLF, supported aliases and units, partial/invalid dates, conflict alternatives, CUE scope, unknown text and bounded/partial reads. PostgreSQL seam tests compose retained reads and snapshots, verify idempotence and revision/parser provenance, and verify that reviewed selections and legacy manual tracklists remain unchanged.
