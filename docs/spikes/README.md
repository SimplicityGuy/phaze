# Historical Spike Archive

The reports, scripts, patches, and captured results below are point-in-time investigation evidence.
Their verdicts, measurements, and operator quotations describe what was observed at their recorded
revision and date; they are not maintained descriptions of the current implementation. Start with
the current [documentation index](../README.md) and accepted records under [`docs/design/`](../design/)
for shipped behavior.

Repository-local links and Mermaid diagrams preserve the repository shape known when a spike was
written. `scripts/audit_historical_evidence.py` checks every local target and Mermaid fence. A
missing target reported as `historical_by_boundary` is intentionally retained as point-in-time
provenance, not promised as current navigation.
