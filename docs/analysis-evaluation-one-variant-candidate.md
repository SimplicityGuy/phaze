# First performance candidate: one variant per characteristic

This is an **Essentia-based optimization experiment**, not a clean-room implementation. It provides a runnable candidate for the paired UpCloud harness while a true independent replacement remains future work.

The current coarse tier performs 33 binary classifier sweeps (11 result families × 3 model variants) plus one Discogs400 genre sweep per chunk. This candidate keeps the MusiCNN-MSD variant for each of the 11 families and keeps the same Discogs400 genre sweep: 12 sweeps total. It uses the current fine-tier BPM/key algorithms unchanged. All 30-second fine and 180-second coarse windows remain exhaustive. It still emits all seven mood scores, danceability, gender, tonality, voice/instrumental, ranked styles, dominant style, energy, BPM, key, and complete window counts through the neutral harness protocol. The two omitted variants can change classifier probabilities and labels; field presence and speed alone do not establish quality.

The candidate is isolated in `scripts/analysis_eval_candidate_one_variant.py` and staged on the host at `/home/datum/phaze-iq64v/candidate/analyze.py`. It selects one model per family in the evaluation child process, leaves production source and saved baselines unchanged, and normalizes the result through the existing wire adapter. `scripts/analysis_eval_stage_one_variant_models.py` hard-links the 12 `.pb`/`.json` pairs already downloaded on the host into the private candidate model directory. The exact selected model-tree digest is recorded by the harness. The image is the already-pinned production-equivalent image; no new image or image digest needs to be supplied by the operator.

The completed smoke and full passes were launched by `/home/datum/phaze-iq64v/code/start-analysis.sh`; the repeat used `/home/datum/phaze-iq64v/code/repeat-analysis.sh`. The full passes took 96.4 and 92.7 minutes, for 2.025× and 2.108× speedups against the faster incumbent pass. Both had 8/8 files, zero failures, and complete fine/coarse coverage. The two passes produced identical normalized predictions. Current DB analysis values are incumbent behavior, and only four source genre tags have reviewable broad-family mappings. The 65/208 changed coarse mood labels and other characteristic changes require independent quality review; BPM/key, characteristic quality, and transition accuracy remain unverified without further labels. The production adoption is a separate bead, `phaze-0sec0`.
